# Royal Thanjavur Decor

build a landing page for a business called royal decor thanjavur. this is a decor business focusing on stage decoration, and function decorations.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
